# Resume Scorer

Completed local web application built with Python 3.10+, Streamlit, LangGraph, LangChain's Ollama connector, Ollama, PyMuPDF, Pydantic, requests, and BeautifulSoup. It uses a local Qwen3:4b model by default and does not require an API key. The user uploads a PDF résumé and provides a job description as pasted text or a link. The app returns a match score out of 100 with skills, experience, keywords, and education breakdowns; identifies important missing job keywords; and provides concrete improvement suggestions without recommending invented experience. Errors explain what happened and what to do next. While scoring is running, the Score action is locked and Stop is available; stopping ends work immediately. New requests begin clean without old errors or results. Playwright with headless Chromium is an optional path for JavaScript-built job pages. The app runs on the user's computer; no public deployment or repository has been provided.
